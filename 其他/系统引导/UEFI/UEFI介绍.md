
| 对比项       | BIOS            | UEFI                         |
|--------------|-----------------|------------------------------|
| 启动模式     | 传统启动（MBR） | 现代启动（GPT）              |
| 存储容量支持 | 最大 2TB 硬盘   | 支持超过 2TB                 |
| 启动速度     | 较慢            | 更快                         |
| 界面         | 文字界面        | 图形化界面、鼠标操作         |
| 扩展能力     | 固定、难扩展    | 模块化、可扩展               |
| 安全性       | 无安全验证      | 支持 Secure Boot（安全启动） |




1. 电源开启，主板加载 UEFI 固件.
2. UEFI 初始化硬件.
3. UEFI 读取启动配置(如 EFI 系统分区).
4. 加载操作系统引导程序(如 bootx64.efi).
5. 操作系统接管控制权.


查看是否是uefi 启动.


1. 文件是否存在

   ```bash
   ls -la /sys/firmware/efi
   ```

2. `sudo efibootmgr` 命令

   有显示则是 UEFI 启动.
