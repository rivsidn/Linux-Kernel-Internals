## 基本架构

### 功能框架

```

                             +-----------+
                     +-------| Bootstrap | --------+
                     |       +-----------+         |
                     |                             |
                     |                             |
                     v                             v
                +--------+                   +------------+
                | Docker |                   | Qemu-image |
                +--------+                   +------------+

```

首先生成Bootstrap，然后依次生成Docker 和 Qemu-image.

### 文件目录

```bash
kernel_debug_system/
├── ubuntu.conf
│   ├── ubuntu-5.10.conf
│   ├── ubuntu-6.06.conf
│   ├── ubuntu-7.04.conf
│   ├── ubuntu-8.04.conf
│   └── ubuntu-10.04.conf
├── generate_rootfs.py
└── bootstrap_manager.sh
```

#### 文件目录说明

| 目录/文件            | 说明         |
|----------------------|--------------|
| kernel_debug_system/ | 功能主目录   |
| ubuntu.conf/         | 配置文件目录 |


## 构建根文件系统

```
[ubuntu-5.10]
version=5.10
suite=breezy
architectures=i386
kernel_versions=2.6.12
```
