
## 代码实例

```c
static int get_e820_md5(struct e820_table *table, void *buf)
{
	struct crypto_shash *tfm;
	struct shash_desc *desc;
	int size;
	int ret = 0;

	//获取算法
	tfm = crypto_alloc_shash("md5", 0, 0);
	if (IS_ERR(tfm))
		return -ENOMEM;

	//填充desc结构体
	desc = kmalloc(sizeof(struct shash_desc) + crypto_shash_descsize(tfm),
		       GFP_KERNEL);
	if (!desc) {
		ret = -ENOMEM;
		goto free_tfm;
	}

	desc->tfm = tfm;
	desc->flags = 0;

	size = offsetof(struct e820_table, entries) +
		sizeof(struct e820_entry) * table->nr_entries;

	//计算hash值
	if (crypto_shash_digest(desc, (u8 *)table, size, buf))
		ret = -EINVAL;

	kzfree(desc);

free_tfm:
	crypto_free_shash(tfm);
	return ret;
}
```

## 函数接口

### crypto_alloc_shash

```c
struct crypto_shash *crypto_alloc_shash(const char *alg_name, u32 type, u32 mask)
```

crypto_alloc_shash 是 Linux 内核加密 API
中用于分配同步哈希算法转换对象的函数。它返回一个
可以用来计算消息摘要(如 MD5、SHA1、SHA256
等)的转换句柄。

#### 参数说明

1. alg_name (const char *)
  - 要分配的哈希算法名称
  - 在你的代码中是 "md5"
  - 其他常见值: "sha1", "sha256", "sha512" 等
  - 可以通过 /proc/crypto 查看系统支持的所有算法
2. type (u32)
  - 指定算法的类型标志
  - 在现代内核中,对于简单的哈希算法分配通常设置为
 0
  -
这个参数主要用于更复杂的场景,如指定特定的算法特性
3. mask (u32)
  - 用于过滤算法实现的掩码
  - 设置为 0 表示接受任何实现(硬件加速或软件实现)
  - CRYPTO_ALG_ASYNC 可以用来排除异步实现

#### 返回值

- 成功: 返回指向 struct crypto_shash 的指针
- 失败: 返回 ERR_PTR 编码的错误码,可用 IS_ERR()
和 PTR_ERR() 检查
