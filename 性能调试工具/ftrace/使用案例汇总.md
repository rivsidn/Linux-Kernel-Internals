
## 追踪函数内部调用

通过设置`set_graph_function` 可以查函数内部调用其他函数的过程.

```bash
cd /sys/kernel/debug/tracing

# 关闭当前 tracer
echo nop > current_tracer
# 清空
echo > trace

# 设置 graph tracer
echo function_graph > current_tracer

# 只以 tcp_sendmsg 作为 root
echo tcp_sendmsg > set_graph_function

# 开启
echo 1 > tracing_on

# 触发你的场景...

# 关闭
echo 0 > tracing_on

# 查看结果
cat trace

```
